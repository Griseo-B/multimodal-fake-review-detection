## 仓库怎么用

```
docs/           方案、中期/结项文稿
papers/         文献说明（大文件本地存，不上传）
data/           数据说明与表格模板（原始数据不上传）
code/           数据处理、训练、评估、解释
experiments/    每次实验结果记录
```

## 到中期前

1. 搜集公开数据集， `data/数据集清单.csv`
2. 定三类标签规则，少量自补并标注
3. 跑通基线，写出可复现结果
4. 准备中期报告

## 三类标签

| 标签 | 含义 | 英文建议值 |
|------|------|------------|
| 真 | 真实用户评论 | `real` |
| 人假 | 人工编写的虚假评论 | `human_fake` |
| AI假 | AI 生成的虚假评论 | `ai_fake` |
