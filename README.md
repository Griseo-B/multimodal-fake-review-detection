# 大模型驱动的多模态虚假评论可解释检测与 AI 生成识别研究

中国人民大学「求是学术」品牌研究项目（2026）

| 项目 | 内容 |
|------|------|
| 书院 | 明理书院 |
| 负责人 | 许珀铭 |
| 指导教师 | 杜玮 |
| 团队 | 许珀铭、覃玉雯、管文馨、朱启哲、朱明哲 |

## 仓库怎么用

```
docs/           方案、中期/结项文稿
papers/         文献说明（大文件本地存，不上传）
data/           数据说明与表格模板（原始数据不上传）
code/           数据处理、训练、评估、解释
experiments/    每次实验结果记录
finance/        经费台账模板（发票本地存，不上传）
```

## 近期目标（到中期前）

1. 搜集公开数据集，填好 `data/数据集清单.csv`
2. 定三类标签规则，少量自补并标注
3. 跑通基线，写出可复现结果
4. 准备中期报告；11 月前完成报销

## 三类标签

| 标签 | 含义 | 英文建议值 |
|------|------|------------|
| 真 | 真实用户评论 | `real` |
| 人假 | 人工编写的虚假评论 | `human_fake` |
| AI假 | AI 生成的虚假评论 | `ai_fake` |

## 快速开始

1. 两位理科同学按 `data/README.md` 填写数据集清单  
2. 非理科同学按 `data/templates/标注规范.md` 与标注表工作  
3. 实验记录写入 `experiments/`  

更完整的执行计划见 `docs/执行方案摘要.md`。
