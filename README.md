## 仓库怎么用

```
docs/实验进展.md   唯一的进展记录，新结果往文末追加
data/              冻结表、原始数据和说明
code/              清洗、训练、评估、解释
experiments/       每次运行的指标文件
papers/            文献说明
```

先读 `docs/实验进展.md`。

## 三类标签

| 标签 | 含义 | 英文值 |
|---|---|---|
| 真 | 真实用户评论 | `real` |
| 人假 | 人工编写的虚假评论 | `human_fake` |
| AI假 | AI 生成的虚假评论 | `ai_fake` |
