# 数据目录说明

- **公开数据优先**，
- **原始大数据不上传 GitHub**（已在 `.gitignore` 忽略）

## 文件夹

| 路径 | 用途 |
|------|------|
| `raw/` | 原始下载数据（本地存放） |
| `processed/` | 整理后的统一格式数据（本地存放） |
| `templates/` | 清单表、标注表、规范 |

## 找公开数据集

找到后请填写：`数据集清单.csv`（模板见同目录）。

每个数据集至少写清：

1. 名称  
2. 下载链接  
3. 大约条数  
4. 有没有图片  
5. 原有标签是什么  
6. 能否对应到：真 / 人假 / AI假  
7. 是否已下载到本地  
8. 一句话是否推荐使用  

## 统一样本字段（处理后）（可暂时忽略）

整理进 `processed/` 时，建议每条包含：

| 字段 | 说明 |
|------|------|
| `id` | 唯一编号 |
| `text` | 评论文字 |
| `image_path` | 图片路径，没有则空 |
| `label` | `real` / `human_fake` / `ai_fake` |
| `domain` | 场景：hotel / food / ecommerce 等 |
| `source` | 来自哪个数据集，或自建 |
| `gen_source` | 若是 AI 假：用的哪个模型；否则空 |
| `split` | `train` / `val` / `test` |
